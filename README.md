# Vehicle Loan Analysis Dashboard

A Power BI dashboard for analyzing vehicle loan applications, funding performance, risk levels, customer financial indicators, and loan trends.

## Dashboard Overview

This project provides interactive insights into vehicle loan data through two dashboard pages:

- **Summary Dashboard:** Highlights funded amount, received amount, average interest rate, DTI ratio, total loan applications, loan stage, risk category, and vehicle type.
- **Overview Dashboard:** Shows monthly application trends, ownership status, loan tenure, vehicle type distribution, and dealer-state performance.

## Key Metrics

| Metric | Value |
|---|---:|
| Funded Amount | 5bn |
| Amount Received | 3bn |
| Average Interest Rate | 14.50% |
| Average DTI Ratio | 15.16% |
| Total Loan Applications | 5K |

## Key Insights
- Most vehicle loan applications are in the **Active** loan stage.
- Good-risk loans represent the majority of loan accounts.
- Vehicle type is an important factor in loan application distribution.
- Monthly loan application trends help identify periods of high and low demand.
- Ownership status, loan tenure, and dealer state provide additional insights into customer and dealer performance.

## Dashboard Features
- Vehicle type filter
- Risk category filter
- Loan stage analysis
- Monthly loan application trend
- Funded amount versus received amount comparison
- Loan applications by vehicle type
- Loan applications by ownership status
- Loan applications by tenure months
- Loan applications by dealer state
